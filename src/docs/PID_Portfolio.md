# Project Initiation Document (PID) – Portfolio Website

## Project Overview
The goal is to design and build a professional portfolio website for Walter Okumu Oriaro, showcasing his unique positioning as a Technical Customer Success Architect / Full-Stack Engineer.

## Objectives
- Establish a professional online presence.  
- Present skills, experience, and case studies.  
- Provide a blog for thought leadership content.  
- Enable secure client engagement via forms and booking tools.  
- Optimize for SEO and analytics.

## Scope
- **In-scope**: Branding, website design, blog, SEO, analytics, contact form.  
- **Out-of-scope**: eCommerce, large-scale CMS (initially).

## Deliverables
- Fully responsive website (Next.js 15, Tailwind CSS).  
- MDX-powered blog.  
- Secure contact form with Nodemailer.  
- Deployment docs for Ubuntu, Vercel, and AWS.

## Constraints
- JavaScript only (no TypeScript).  
- Remote-first client base.  
- Security: No public resume download, no direct email exposure.

## Assumptions
- Content provided by Walter.  
- Design based on Brand Guide.  
- Infrastructure aligns with current stack (Ubuntu + Apache2 + PM2).

## Risks
- Scope creep if additional CMS is introduced.  
- SEO visibility depends on regular content updates.  
- Security risks around form handling (mitigated with captcha/validation).

## Governance
- **Sponsor**: Walter Okumu Oriaro  
- **Approver**: Walter Okumu Oriaro  
- **Change Control**: Updates reviewed before implementation.
